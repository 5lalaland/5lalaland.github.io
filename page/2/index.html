1. Agent 基础知识1.1 什么是 AI Agent？定义： AI Agent（人工智能智能体）是能够根据用户目标，自主获取信息、进行推理和任务规划，并通过工具执行操作的 AI 系统。与普通 LLM 主要负责生成内容不同，Agent 不仅能够回答问题，还可以访问文件、调用 API、查询数据库、发送邮件甚至操作计算机。LLM 与 Agent 的区别： 1. LLM（大语言模型）：主要负责理解输入、推理和生成输出，例如 ChatGPT、Qwen 背后的语言模型。2. Agent（智能体）：以 LLM 为核心，结合工具、记忆、任务规划与执行框架，实现多步骤任务。3. Workflow（工作流）：按照预先定义的流程执行任务，步骤通常比较固定；Agent 则可以根据任务和执行结果动态选择下一步，但两者可以结合。例子： 用户说“帮我总结今天收到的重要邮件并整理成报告”。普通 LLM 无法仅凭自身参数获取私人邮箱中的实时邮件，而具有授权邮件工具的 Agent 可以调用邮件 API → 获取邮件 → 分析内容 → 筛选重要信息 → 生成报告。 1.2 Agent 的核心组件1.
