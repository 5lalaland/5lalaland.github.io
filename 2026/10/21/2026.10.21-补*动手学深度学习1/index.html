8.softmax
MNIST：识别10个数字
ImageNet:自然物体分类
分类：y=[y1,y2,y3,..yn]
y_i=1 if i=y（真实类别），否则为0
y_hat=argmax_i(o_i)
o_y-o_i > Δ(y,i)（分类间隔阈值）

cross entropy:交叉熵 衡量两个概率分布之间的差异

交叉熵：-∑ y_i log(y_hat_i)
又因为yi当中有且只有对应的真实的那一个y是1，其他的都是0
所以 l=-log(y_right) y_right是真实的y对应的x预测出来的y_hat

常用的LOSS：
1.均方损失 1/2(y-y’)^2
2.绝对值 |y-y’|
3.Huber（鲁棒）损失

写法 英文全称 中文意思 记忆点 / 你代码里的场景
net network 模型 / 网络 模型的通用别名，写net=linreg，后面换模型只改这一行
lr learning rate 学习率 梯度下降每一步迈多大，超参数
w / b weight / bias 权重 / 偏置 模型要自动学的核心参数
X feature matrix 特征矩阵 模型输入，每一行是一个样本
y label / true value 标签 / 真实值 标准答案
y_hat predicted y 模型预测值 头上戴帽子 = 猜出来的结果
features / labels 特征集 / 标签集 整个训练集的 X 和 y
train_iter/test_iter train/test iterator 训练 / 测试集迭代器 分批吐数据的工具
batch_size batch size 批大小 一次喂给模型多少个样本
num_epochs / epoch number of epoch 训练总轮数 / 单轮 完整遍历一遍全部训练数据叫 1 个 epoch
indices index 的复数 样本下标列表 记录 “第几个样本是哪条” 的编号清单
trainer trainer/optimizer 优化器 自动帮你更新 w,b 的工具（比如 SGD）
partition partition sum 分区求和 softmax 里每行指数值的总和
SGD Stochastic Gradient Descent 随机梯度下降 小批量梯度下降算法
