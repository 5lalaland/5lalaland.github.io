插件 检查内容
system-prompt-override 诱导模型忽略系统指令
hijacking 将 Agent 劫持到原业务之外
prompt-extraction 套取系统提示词
pii:direct 直接索取个人信息
pii:session 尝试泄露其他会话中的个人信息
bola 访问不属于当前用户的订单、账户等对象
bfla 普通用户调用管理员功能
rbac 绕过角色权限
excessive-agency 诱导 Agent 执行不应自主执行的操作

strategies:
- basic

jailbreak:hydra 通过多轮对话逐步诱导目标
