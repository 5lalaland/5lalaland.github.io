原理+概念

发表于2026-09-14|更新于2026-10-04|AI Security
|浏览量:

用户任务
↓
【Agent（智能体，逻辑概念）】 负责思考、规划、决定什么时候调用工具
↓
【LangChain（开发框架）】 是实现Agent的代码库，提供Agent运行时、记忆、提示词、工具管理
↓
【MCP（通信协议）】 LangChain通过MCPAdapter，把MCP Server的外部工具接入LangChain Agent
↓
MCP Server（文件、数据库、API、计算器）

MCP:模型上下文协议，用来让 Agent 标准化调用外部工具 / 服务。

  • 写一次 MCP Server，任何支持 MCP 的 Agent（LangChain、Claude Desktop、Cursor）都可以直接调用；

  • 工具能力自动发现，不用硬编码工具列表；

  • 统一权限边界，隔离外部系统，方便管控安全。
    不负责思考推理，只管 Agent 和外部工具之间的标准化通信。

  • Host（AI 应用 / Agent）：用于协调和管理一个或多个 MCP 客户端的 AI 应用程序

  • MCP Client ：一个维护与 MCP 服务器连接并从 MCP 服务器获取上下文以供 MCP 主机使用的组件。
  • MCP Server：一个为 MCP 客户端提供上下文信息的程序

Agent:根据信息进行推理/规划并采取行动的AI智能系统
组件：

  • 大脑：LLM:chatpgt,qwen等

  • 记忆：大模型记住之前的聊天和操作，利用背景和上下文

  • 工具：互动的主要方式

    1. 主动获取上下文信息：检索数据并搜集文档
    2. 采取行动：收发邮件，增删数据库
    3. 编排：调用其他代理，触发工作流
      大部分是单agent 也可以用多Agent

  • API = 两个程序交流的接口：定义与规定了可以发送什么请求并且获得什么数据
    常用Get/Post方式，采用json格式
    https://example.com/api/chat 是 API 地址
    sk-xxxxxxxx是 API Key，证明我有权限调用这个 API

东西 例子 作用
API地址 https://xxx.com/api/chat 去哪里调用
API Key sk-xxxx 证明身份
Token eyJxxx 登录凭证
参数 {“message”:”hello”} 发送的数据

搭建agent平台:n8n

LangChain:开源的python AI应用开发框架，提供了摸快和工具
功能：

  • 统一接口：管理LLM和prompt
  • chain：智能流水线，把多个组件链接起来
  • LCEL：灵活自定义整个AI任务的处理流程
  • RAG:检索增强，全套工具
  • agent：LLM为核心的决策引擎
  • memory：让大模型记住部分对话

组成：

  1. langchain libraries:提供多个包，框架清晰
  2. langchain templates:langchain 提供的官方模版
  3. langchain serve :基于fastapi将langchain的链发布为rest api
  4. langsmith:开发平台，适合debug
