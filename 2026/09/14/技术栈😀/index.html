路线
如果按 AI Security 实习优先级：

  1. Prompt Injection + Jailbreak

  2. RAG + RAG Security

  3. Agent + MCP + API Security

  4. Promptfoo + Garak + Red Teaming

  5. LoRA + SFT + RLHF/DPO

  6. Data Poisoning + Backdoor

  7. MIA + Privacy

  8. Deployment（vLLM/TensorRT-LLM）

  9. Defense(DP,Federated learning)

  10. LLM基础： Transformer、Attention、Decoder-only LLM、Tokenizer、Embedding、Logits、KV Cache、长上下文

  11. Prompt Engineering： System Prompt、Few-shot、CoT、ReAct、Prompt Template、Context Management

  12. LLM Agent： Agent架构、Planner、Tool Calling、Memory、Workflow、LangChain、LangGraph、MCP、API调用

  13. RAG技术： Document Loader、Chunking、Embedding、Vector Database、Retriever、Rerank、Hybrid Search、FAISS、Milvus、Chroma

  14. RAG Security： Document ACL、Metadata Filtering、Permission-aware Retrieval、RAG Injection、Document Sanitization、Context Isolation、Data Leakage Prevention

  15. Prompt Injection攻击： Direct Prompt Injection、Indirect Prompt Injection、Jailbreak、Role Play Attack、Encoding Attack（Base64/Leetspeak）、Multi-turn Attack

  16. Prompt Injection防御： Input Filtering、Prompt Classifier、Intent Detection、Adversarial Training、Output Guard、System Prompt Protection

  17. Jailbreak攻击： GCG、AutoDAN、DAN、Crescendo、Deceptive Delight、Adversarial Suffix

  18. LLM安全测试工具： Promptfoo、Garak、PyRIT、LLM Red Teaming、OWASP LLM Top 10、MITRE ATLAS

  19. LLM漏洞评估： Prompt Injection Detection、Data Leakage Testing、Hallucination Detection、Toxicity Detection、Safety Benchmark

  20. Fine-tuning技术： SFT、LoRA、QLoRA、Adapter、PEFT、Full Fine-tuning

  21. 模型训练安全： Data Poisoning、Backdoor Attack、Clean-label Poisoning、Trigger Detection、Dataset Filtering

  22. 模型后门防御： Trigger Scanning、Activation Analysis、Parameter Inspection、Model Watermarking、Pruning

  23. 隐私攻击： Membership Inference Attack（MIA）、Model Inversion Attack、Training Data Extraction、Memorization Analysis

  24. 隐私保护： Differential Privacy、DP-SGD、Gradient Clipping、Noise Injection、Federated Learning

  25. 模型遗忘： Machine Unlearning、SISA、Gradient Ascent Forgetting、Selective Forgetting

  26. 安全对齐： RLHF、SFT Alignment、Reward Model、PPO、DPO、Constitutional AI

  27. Reward Model： Bradley-Terry Model、Pairwise Ranking Loss、Preference Learning、Reward Hacking

  28. 强化学习安全： PPO、KL Divergence Constraint、Policy Optimization、Reward Exploitation

  29. 多模态安全： VLM Security、Image Prompt Injection、OCR Attack、Cross-modal Jailbreak、Image Sanitization

  30. 模型部署： vLLM、TensorRT-LLM、FastTransformer、CUDA、GPU Inference Optimization

  31. 分布式推理： Tensor Parallelism、Pipeline Parallelism、Data Parallelism、Model Parallelism

  32. LLM工程开发： Python、PyTorch、Transformers、FastAPI、Docker、Linux、CUDA环境

  33. API安全： REST API、API Key、Authentication、Authorization、Rate Limiting、Access Control

  34. 安全架构设计： Input Guard → LLM → Tool Guard → Retrieval Guard → Output Guard、Defense-in-depth

  35. 幻觉与违规检测： Hallucination Detection、Fact Checking、Self-Consistency、Guard Model、Safety Classifier

  36. 最新LLM技术： MoE、Long Context、Flash Attention、Speculative Decoding、Agentic AI、Reasoning Model

  37. 安全标准框架： OWASP Top 10 for LLM、MITRE ATLAS、NIST AI RMF、AI Safety Benchmark
