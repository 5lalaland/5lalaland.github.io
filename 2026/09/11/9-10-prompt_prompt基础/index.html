prompt基础

发表于2026-09-11|更新于2026-10-04|AI Security
|浏览量:
  1. Prompt基础
  • System Prompt
    开发者给模型设定的最高级规则。
    { “role”:”system”, “content”:”You are a helpful assistant” },
    比user的信息的地位高，可以一定的防护User的prompt;但是会面临system prompt泄漏的问题
  • User Prompt
    用户输入的信息。
  • Developer Message
    这是应用开发者设置的指令。
  • Instruction Hierarchy
    不同消息有不同优先级。 system>developer>user
  • Context Window
    上下文窗口：模型一次能够看到的信息长度。gpt:128k 面临过长上下文攻击或者上下中藏有攻击指令
  • Prompt Template
    开发者提前设计固定格式。：
    You are a customer service bot.

    Customer question:

    {question}//替换用户输入。

    Answer:
  • Few-shot Prompting
    给模型几个例子，让它学习格式。
  • Chain-of-Thought（CoT）
    让模型逐步推理。
  • ReAct Prompting
    Reason + Act 让模型进行思考->行动->结果->继续思考 让模型具有工具调用能力。
