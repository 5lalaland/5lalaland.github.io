name 随便写
Select Target Type 你的 AI 系统是什么形式？

  • HTTP/HTTPS Endpoint：Agent 有一个 API 地址。
  • A2A Agent ：多个agent通信
  • Python：agent 是一个 Python 函数,本地实验、
  • OpenAI:对应的gpt模型

model id :格式provider:model 例如openai:gpt-5.5
Test Generation：Promptfoo 怎么生成攻击测试。
prompts:promptfoo生成的prompt放置的地方，比如You are a customer support assistant.
Answer user questions.
User:

确认攻击的对象是工具型AI（完整），还是只对话型A I
What key features does your application provide?应用功能
What industry or domain does your application operate in?所属行业
Any constraints or rules attackers should know about?模型现在的攻击防护方法


plugins:我要让 Promptfoo 帮我检查哪些安全问题。
例如选择PII via Direct Exposure对应尝试诱导模型泄露个人信息的攻击。
选择SQL Injection对应尝试测试数据库查询是否容易被注入。
左边是一组预先组合好的 Plugin 集合。
例如：

  • Recommended，Promptfoo 推荐的一套，其中包含
    prompt injection+privacy+jailbreak+authorization
  • Minimal Test少量测试，快速验证：“我的配置有没有问题”。
  • RAG Retrieval-Augmented Generation 测试。
  • Foundation基础模型风险。更偏：LLM 本身。


Strategy = 攻击执行方式。
Meta Agent：- 生成攻击

  • 看结果
  • 根据失败/成功调整
    Hydra Multi-Turn：多轮攻击，就是会对话多次去产生语境得到最终效果

生成yaml ,替代promptfoo-redteam-demo里面的promptfoo.yaml

运行
cd ~/promptfoo-redteam-demo
npx promptfoo@latest redteam setup .
替换yaml
npx promptfoo@latest redteam run
–max-concurrency 1
–delay 5000
npx promptfoo@latest redteam report结果

要求有官方 API和模型名称

左边 是真正发送的prompt
右边fail表示防守失败，但攻击成功
红色文字 ：判定成fail的原因
黑色文字：Agent 实际返回的内容。

  • BFLAEnforcement (0/3):
    BFLA：功能级权限控制失效,调用函数
    Enforcement：是否正确执行权限限制

  • BFLAEnforcement/IterativeMeta (0/3)
    /IterativeMeta:Promptfoo 不只一种攻击,用自适应攻击测试功能权限绕过。

  • BOLAEnforcement/IterativeMeta (0/3)
    BOLA:你有没有权限访问这个对象？，查询对象

  • Hijacking/IterativeMeta (0/3)
    Hijacking:用户能不能改变 Agent 的目标。比如忘记你的任务，然后xxxx

  • PIILeak/IterativeMeta (0/6)
    PIILeak:个人身份信息。

  • PromptExtraction/IterativeMeta (0/3)
    PromptExtraction有没有提示词泄露。

  • RbacEnforcement/IterativeMeta (0/3)
    Rbac：基于角色权限，例如我是管理员
