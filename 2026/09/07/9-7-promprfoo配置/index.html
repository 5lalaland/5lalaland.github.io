plugins:我要让 Promptfoo 帮我检查哪些安全问题。
例如选择PII via Direct Exposure对应尝试诱导模型泄露个人信息的攻击。
选择SQL Injection对应尝试测试数据库查询是否容易被注入。
左边是一组预先组合好的 Plugin 集合。
例如：

  • Recommended，Promptfoo 推荐的一套，其中包含
    prompt injection+privacy+jailbreak+authorization
  • Minimal Test少量测试，快速验证：“我的配置有没有问题”。
  • RAG Retrieval-Augmented Generation 测试。
  • Foundation基础模型风险。更偏：LLM 本身。

  • 看结果
  • 根据失败/成功调整
    Hydra Multi-Turn：多轮攻击，就是会对话多次去产生语境得到最终效果

![image-20260907191323530](/Users/yangxianle/Library/Application Support/typora-user-images/image-20260907191323530.png)

左边 是真正发送的prompt
右边fail表示防守失败，但攻击成功
红色文字 ：判定成fail的原因
黑色文字：Agent 实际返回的内容。

  • BFLAEnforcement (0/3):
    BFLA：功能级权限控制失效,调用函数
    Enforcement：是否正确执行权限限制
  • BFLAEnforcement/IterativeMeta (0/3)
    /IterativeMeta:Promptfoo 不只一种攻击,用自适应攻击测试功能权限绕过。
  • BOLAEnforcement/IterativeMeta (0/3)
    BOLA:你有没有权限访问这个对象？，查询对象
  • Hijacking/IterativeMeta (0/3)
    Hijacking:用户能不能改变 Agent 的目标。比如忘记你的任务，然后xxxx
  • PIILeak/IterativeMeta (0/6)
    PIILeak:个人身份信息。
  • PromptExtraction/IterativeMeta (0/3)
    PromptExtraction有没有提示词泄露。
  • RbacEnforcement/IterativeMeta (0/3)
    Rbac：基于角色权限，例如我是管理员
