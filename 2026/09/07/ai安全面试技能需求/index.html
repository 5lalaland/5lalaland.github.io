OWASP LLM Top 10 Prompt Injection、Data Leakage、Excessive Agency、Supply Chain、Vector Weakness 能针对每个风险设计测试方案和防御措施
LLM Evaluation ASR、Toxicity、Leakage Rate、Refusal Rate、False Positive/Negative 能设计安全 benchmark 和评价指标
LLM Privacy Attack Membership Inference、Training Data Extraction、Memorization、PII Leakage 能复现隐私攻击论文，分析数据泄露风险
RAG Security Embedding、Vector Database、Retriever、Document Injection、Data Poisoning 能攻击和评估 RAG 系统安全性
Agent Security ReAct、Tool Calling、Memory、Planning、Permission Control 能分析 Agent 越权、工具滥用、Memory Poisoning
AI Guardrail Input Filter、Output Filter、Moderation Model、Policy Enforcement 能设计 LLM 安全防护架构
安全评测框架 HELM、OpenAI Evals、lm-eval-harness、BIG-bench 能理解和复现实验评测流程
模型漏洞分析 Prompt Leakage、Backdoor、Data Poisoning、Model Extraction 能分析模型层面的安全风险
开源 LLM 安全实践 Llama/Qwen/DeepSeek 部署、API调用、推理测试 能在本地或API模型上进行安全实验
AI Agent框架安全 LangChain、LlamaIndex、AutoGen、CrewAI 能搭建简单 Agent 并测试攻击面
安全标准与框架 MITRE ATLAS、NIST AI RMF、OWASP GenAI 能将漏洞映射到安全框架
