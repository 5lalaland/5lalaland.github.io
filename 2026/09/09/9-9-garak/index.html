garak | |– probes（攻击测试） | |– detectors（漏洞判断） | |– generators（目标模型接口） | |– buffs（变异增强） | |– reports（结果报告）

提示词probes
python3 -m garak -m huggingface -n gpt2 -p promptinject
读取结果
less garak.xx

参数

  • --model_name huggingface（用于在本地以管道方式运行Transformer模型）
  • --model_type- 请使用 Hub 中的模型名称。
  • --model_name huggingface.InferenceAPI
    • --model_name openai
  • --model_type- 你想使用的 OpenAI 模型text-babbage-001速度很快，适合测试；gpt-4但似乎对许多更隐蔽的攻击比较脆弱。
  • 将OPENAI_API_KEY环境变量设置为您的 OpenAI API 密钥

probes:攻击方法
detectors：determine when an LLM has gone wrong
Harnesses：determine which detectors and which probes will be run
evaluator.:determine what passes

选择probe->garak生成prompt->detector判断是否成功

案例解读
cd /Users/yangxianle/Desktop/promptfoo/garak
mkdir -p reports

cat > shoplab-rest.json <<’JSON’
写入json代码
{
“rest”: {
“RestGenerator”: {
“name”: “ShopLab”,
名字
“uri”: “http://127.0.0.1:8000/chat“,
攻击地址
“method”: “post”,
HTTP方法
“headers”: {
“Content-Type”: “application/json”
},
发送JSON
“req_template_json_object”: {
“message”: “$INPUT”, //garak生成的攻击替换这里
“user_id”: “alice”
},
“response_json”: true,//服务器返回JSON
“response_json_field”: “response”,//服务器返回的答案的位置
“request_timeout”: 650 //等待时间
}
}
}
JSON

python -m garak
表示运行garak当中的main.py
–target_type rest
目标类型，可选：huggingface ,openai,rest(http api)，litellm
–generator_option_file shoplab-rest.json
加载配置文件，写出REST API以及调用
–spec probes.dan.Dan_11_0
攻击选择，probes是攻击库，DAN：忽略安全限制
garak –list_probes当中可以看到选择
–generations 1
生成次数
–parallel_requests 1
并发请求数量。
–parallel_attempts 1
攻击尝试并发。
–report_prefix “PWD/reports/shoplab-dan-(date +%Y%m%d-%H%M%S)”
报告保存位置。
