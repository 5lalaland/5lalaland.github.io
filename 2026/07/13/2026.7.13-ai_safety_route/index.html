技术栈 需要掌握内容 达到标准（结果）
LLM 基础 Transformer、Attention、Decoder-only LLM、Tokenization、Inference流程 能解释 LLM 为什么会产生幻觉、泄露、越狱；能读懂安全论文

Promptfoo YAML配置、provider、test case、assertion、redteam模块 能使用 Promptfoo 对模型进行安全评测并生成报告
Garak Probe、Detector、Generator、Scanner架构 能运行 Garak 扫描模型漏洞，并分析结果
OWASP LLM Top 10 Prompt Injection、Data Leakage、Excessive Agency、Supply Chain、Vector Weakness 能针对每个风险设计测试方案和防御措施
LLM Evaluation ASR、Toxicity、Leakage Rate、Refusal Rate、False Positive/Negative 能设计安全 benchmark 和评价指标
LLM Privacy Attack Membership Inference、Training Data Extraction、Memorization、PII Leakage 能复现隐私攻击论文，分析数据泄露风险
RAG Security Embedding、Vector Database、Retriever、Document Injection、Data Poisoning 能攻击和评估 RAG 系统安全性
Agent Security ReAct、Tool Calling、Memory、Planning、Permission Control 能分析 Agent 越权、工具滥用、Memory Poisoning
AI Guardrail Input Filter、Output Filter、Moderation Model、Policy Enforcement 能设计 LLM 安全防护架构
安全评测框架 HELM、OpenAI Evals、lm-eval-harness、BIG-bench 能理解和复现实验评测流程
模型漏洞分析 Prompt Leakage、Backdoor、Data Poisoning、Model Extraction 能分析模型层面的安全风险
开源 LLM 安全实践 Llama/Qwen/DeepSeek 部署、API调用、推理测试 能在本地或API模型上进行安全实验

  4. RAG技术： Document Loader、Chunking、Embedding、Vector Database、Retriever、Rerank、Hybrid Search、FAISS、Milvus、Chroma

  5. RAG Security： Document ACL、Metadata Filtering、Permission-aware Retrieval、RAG Injection、Document Sanitization、Context Isolation、Data Leakage Prevention

  6. Prompt Injection攻击： Direct Prompt Injection、Indirect Prompt Injection、Jailbreak、Role Play Attack、Encoding Attack（Base64/Leetspeak）、Multi-turn Attack

  7. Prompt Injection防御： Input Filtering、Prompt Classifier、Intent Detection、Adversarial Training、Output Guard、System Prompt Protection

  8. Jailbreak攻击： GCG、AutoDAN、DAN、Crescendo、Deceptive Delight、Adversarial Suffix

  9. LLM安全测试工具： Promptfoo、Garak、PyRIT、LLM Red Teaming、OWASP LLM Top 10、MITRE ATLAS

  10. LLM漏洞评估： Prompt Injection Detection、Data Leakage Testing、Hallucination Detection、Toxicity Detection、Safety Benchmark

  11. Fine-tuning技术： SFT、LoRA、QLoRA、Adapter、PEFT、Full Fine-tuning

  12. 模型训练安全： Data Poisoning、Backdoor Attack、Clean-label Poisoning、Trigger Detection、Dataset Filtering

  13. 模型后门防御： Trigger Scanning、Activation Analysis、Parameter Inspection、Model Watermarking、Pruning

  14. 隐私攻击： Membership Inference Attack（MIA）、Model Inversion Attack、Training Data Extraction、Memorization Analysis

  15. 隐私保护： Differential Privacy、DP-SGD、Gradient Clipping、Noise Injection、Federated Learning

  16. 模型遗忘： Machine Unlearning、SISA、Gradient Ascent Forgetting、Selective Forgetting

  17. 安全对齐： RLHF、SFT Alignment、Reward Model、PPO、DPO、Constitutional AI

  18. Reward Model： Bradley-Terry Model、Pairwise Ranking Loss、Preference Learning、Reward Hacking

  19. 强化学习安全： PPO、KL Divergence Constraint、Policy Optimization、Reward Exploitation

  20. 多模态安全： VLM Security、Image Prompt Injection、OCR Attack、Cross-modal Jailbreak、Image Sanitization

  21. 模型部署： vLLM、TensorRT-LLM、FastTransformer、CUDA、GPU Inference Optimization

  22. 分布式推理： Tensor Parallelism、Pipeline Parallelism、Data Parallelism、Model Parallelism

  23. LLM工程开发： Python、PyTorch、Transformers、FastAPI、Docker、Linux、CUDA环境

  24. API安全： REST API、API Key、Authentication、Authorization、Rate Limiting、Access Control

  25. 安全架构设计： Input Guard → LLM → Tool Guard → Retrieval Guard → Output Guard、Defense-in-depth

  26. 幻觉与违规检测： Hallucination Detection、Fact Checking、Self-Consistency、Guard Model、Safety Classifier

  27. 最新LLM技术： MoE、Long Context、Flash Attention、Speculative Decoding、Agentic AI、Reasoning Model

  28. 安全标准框架： OWASP Top 10 for LLM、MITRE ATLAS、NIST AI RMF、AI Safety Benchmark
