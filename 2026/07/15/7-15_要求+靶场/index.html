要求+靶场

发表于2026-07-15|更新于2026-10-04|AI Security
|浏览量:

招聘信息里反复出现的技能，按出现频率排序

几乎每条招聘都提到的（必须掌握）：

  1. Prompt injection / jailbreaking 实操经验——不是知道概念，是”能不能现场展示一个你发现或复现的bypass”。infosec.qa那篇提到面试环节会直接给候选人一个LLM应用和60分钟时间找漏洞，这是真实的考核方式
  2. PyRIT和Garak——这两个反复出现，你已经装好了，算是覆盖了
  3. OWASP LLM Top 10 和 MITRE ATLAS——这是行业通用的分类语言，几乎所有招聘都提，你目前只是”看过”，需要能对着一个具体案例说出它属于哪个分类
  4. 能写清楚的漏洞报告——报告质量是区分优秀红队和普通红队的关键，这个恰好是你论文写作能力可以直接迁移的地方

PhD/研究方向岗位（更贴近你想走的路线）： ByteDance那个AI Security PhD实习明确写了在NeurIPS/ICML/ICLR/ACL/EMNLP等顶会有强发表记录是核心门槛——这再次说明，你现在手上这篇论文比任何”多装一个工具”都重要。

Anthropic Frontier Red Team这类顶尖岗位： 要求在竞赛性CTF、漏洞赏金或其他安全相关竞赛中有过往战绩——这提示了一个你还没覆盖的技能面：实战CTF经验。

需要”实地操练”而非”了解概念”的技术清单

结合招聘要求和你已有基础，这几项必须动手，不能只读论文：

  1. Prompt injection / jailbreak的手动构造和绕过——你已经在做了（manual_injection_test.py那次），继续深化
  2. 至少完整跑通一次”设计payload → 测试 → 计算ASR → 写报告”的完整流程——不需要工具多，但要有一次”从头到尾自己做决策”的完整经验，而不是套用教程命令
  3. 靶场类实战——这是你目前完全没做过的部分，也是CTF经验的入口

具体靶场/例子推荐（这是你问的重点）

Gandalf (Lakera)——https://gandalf.lakera.ai 免费、无需安装，纯网页界面。7-8个递进关卡，每一关都是”从一个越来越强的guardrail里套出密码”，本质是练手动prompt injection的直觉。建议现在就去玩一遍，不需要环境，30分钟能感受到”guardrail怎么被绕过”的第一手体验，这个经验比读十篇论文都直接。

HackTheBox AI Red Teamer Path——这是HTB和Google合作的路径，覆盖prompt injection、模型隐私攻击、对抗性AI、供应链风险和部署威胁，理论与动手结合。这个可能需要付费订阅，但如果你想要一个结构化、有认证价值的实战路径（简历上能写），这个值得考虑，尤其里面有一个专门讲LLM输出漏洞和不安全LLM应用的模块，还有防御模块，讲对抗训练和guardrail的实现——这个防御视角补充了你目前只做攻击测试的短板。

Gray Swan AI 的 Arena（如果还在运营，可以搜索确认）——这是GCG论文团队衍生出来的平台，经常举办公开的jailbreak竞赛，某种程度上是CTF在AI安全领域的对应物，参与并有名次是简历亮点。
